Le Football

Description:

Le Football est un sport d'équipe qui se joue entre deux équipes de onze joueurs chacune.

Caractéristiques:

Le Football se joue sur un terrain rectangulaire avec un cage à chaque extrémité.

  • Chaque équipe admet un staff qui la soutient pendant le match.
  • Le but du jeu est de marquer des buts en envoyant le ballon dans le but adverse.
  • Les joueurs doivent respecter les règles du jeu et éviter les fautes.
